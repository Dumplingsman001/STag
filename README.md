# STag · 模块化 SKU 标签系统

STag 是一个 Windows 桌面小工具，用来快速查询 SKU，并用「模块化标签」的方式维护附加信息。

它的核心不是“给 SKU 加几列标签”，而是：

> **SKU 是主表，每个标签模块是一张独立的小表；查询时按 SKU 编码 join。**

这样每个模块只存自己有哪些 SKU，不需要在一张超大 Excel 里留大量空单元格。

## 一、功能

- 单 SKU 查询：输入编码即可查询，也支持悬停或快捷键触发
- 批量查询：一次最多 200 个编码，自动去重
- 模块矩阵：每个标签模块是一块积木，可导入、停用、删除、查看版本
- Excel 导入/导出：模块数据来自普通 Excel，程序提供空白模板
- 数据源切换：支持本地路径，路径找不到时会自动在程序目录下查找
- 暗色无边框界面：收起到系统托盘，可配置开机启动

## 二、目录结构

仓库只包含源码和构建资源：

| 文件 | 说明 |
|---|---|
| `README.md` | 项目说明 |
| `config.json` | 数据源配置，路径支持相对路径 |
| `src/stag.py` | STag 主程序源码 |
| `src/sku_lookup.py` | SKU 查询 / OCR / 弹窗核心 |
| `src/build_stag.py` | 打包脚本 |
| `src/assets/icon.ico` | 程序图标 |
| `src/assets/stag_logo.png` | 界面字标 |

以下内容只存在于本机，不会提交到仓库：

- `data/`（实际使用的 Excel）
- `STag.exe`（打包产物）
- `stag.log`（运行日志）
- 本机模块库和导入缓存
- `__pycache__/`、虚拟环境等

## 三、运行环境

- Windows 10 / 11（64 位）
- Python 3.10+
- 主要依赖：`pystray`、`Pillow`、`pywin32`、`openpyxl`、`winrt-*`、`pyinstaller`

```bash
pip install pystray Pillow pywin32 openpyxl pyinstaller
pip install winrt-runtime winrt-Windows.Foundation winrt-Windows.Foundation.Collections \
            winrt-Windows.Globalization winrt-Windows.Graphics.Imaging \
            winrt-Windows.Media.Ocr winrt-Windows.Storage.Streams
```

## 四、快速开始

1. 克隆仓库并安装依赖（见上）。
2. 准备数据源 Excel。可以打开程序，在查询页点 **导出模板** 生成空白表，再填入自己的数据。
3. 按实际文件名修改 `config.json` 中的 `data_source.path` 和 `operations.path`；也可以直接填绝对路径。
4. 运行程序：

```bash
python src/stag.py
```

5. 打包成单文件 exe：

```bash
python src/build_stag.py
```

生成的 `STag.exe` 会放在项目目录，旁边的 `config.json` 会被保留。

## 五、数据源格式

`config.json` 支持两份 Excel：

| 配置项 | 用途 | 关键列 |
|---|---|---|
| `data_source` | SKU 主表 | `sku编码`、`sku名称`、库存列 |
| `operations` | 负责人对照表 | `编码`、`负责人`、`助理` |

实际列名可以在 `config.json` 里改。路径可以写相对路径；找不到时，程序会在 exe 旁边的 `data` 文件夹中按文件名查找。

仓库不附带任何真实数据；使用时请准备自己的空白表并填入数据，不要把真实数据提交回仓库。

## 六、界面

- **查询页**：单 SKU 查询、批量查询、模块矩阵、已有列、最近动作
- **设置页**：SKU 数据源、负责人关系、触发方式、弹窗显示、开机启动

窗口使用无边框暗色标题栏：拖顶部移动，双击顶部最大化，右下角拖动缩放；右上角 `—` / `×` 收起到托盘，彻底退出用托盘菜单。

## 七、新建模块

1. 在查询页点 **导出模板**，保存空白 Excel。模板只预置 `SKU编码`、`SKU名称（参考）` 两列，标签列名从 C1 开始自己填，不需要的列留空。
2. 填好 Excel 后，点 **+ 新建模块**，选择这个 Excel。
3. 在弹出窗口里填模块名称（例如 `防护配件`），选颜色。
4. 点 **导入为模块**。
5. 模块矩阵里出现一块新积木。

模块名称只在导入时填写，不会写回 Excel。

### 模块 Excel 格式

```text
SKU编码      SKU名称（参考）    标签A     标签B
SKU-0001     示例产品           有        96%
SKU-0002     示例产品           有        95%
```

- 第一列固定：`SKU编码` 或 `编码`
- 含“名称”的列只用于人工查看，导入时忽略
- 其余每一列都是一个标签列
- 一行一个 SKU
- 空值不写入模块
- 单元格字体颜色会随标签一起导入，查询弹窗按 Excel 里设置的颜色显示
- 再次导入同一模块 = 全量替换这个模块的当前数据，并生成一个新版本

## 八、模块矩阵

- 每块积木 = 一个模块
- 面积按数据量（行 × 列，开方压缩）
- 块上显示模块名、前几列、SKU 数、列数、更新时间
- 点击积木：打开模块详情
- 右键积木：打开 / 停用 / 删除
- 停用后积木变暗，批量查询不再包含这个模块
- 删除是软删除，历史版本和动作记录保留

## 九、模块详情

- **导入更新**：重新导入这个模块，全量替换并生成新版本
- **导出当前**：导出当前模块的 SKU + 名称 + 所有列
- **版本历史**：查看版本，撤回最近一次导入
- **停用 / 启用**
- **删除模块**
- **模块颜色**：点击色块立即修改，矩阵积木和弹窗标题颜色同步更新
- 点击列头：按该列排序；再点一次切换升序 / 降序

初版撤回只支持**最近一次导入**；更早版本的回滚后续再做。

## 十、查询与批量查询

### 单 SKU

查询页输入编码，或悬停 / 快捷键触发。弹窗会在负责人信息下面显示模块标签：

```text
标签A     有
标签B     96%
```

- 模块名默认不显示；在设置页打开“显示模块名称”后，会在列名上方显示小标题
- 每个“列名 + 值”占一行
- 标签值的文字颜色继承 Excel 单元格字体颜色

弹窗右上角有 **批量**，点击直接打开批量查码窗口。

### 批量查码

- 每行一个 SKU 编码，不要逗号
- 自动去重，最多 200 个
- 表头先显示基础列，再按模块显示每一列
- 表格可以左右滑动查看所有模块列
- 停用的模块不会出现在批量结果里

## 十一、已知限制

- 模块库是本机 SQLite，多台设备之间不自动同步
- 模块导入是全量替换，不是增量合并
- 撤回只支持最近一次导入
- 模块详情表格显示前 500 个 SKU
- 标签列没有枚举限制，值完全自由填写

## 十二、双击 exe 没反应时

1. 先看任务管理器里有没有 `STag.exe`。如果有，可能已经在托盘/后台运行；双击 exe 会尝试把它拉到前台，也可以右键托盘图标 → **打开查询页**。
2. 如果任务管理器里没有进程，检查 Windows 安全中心 → 病毒和威胁防护 → 保护历史，以及 SmartScreen 是否拦截了未签名程序。
3. 从网络下载的 exe，右键 → 属性 → 勾选“解除锁定”，或先复制到本机磁盘再运行。
4. 需要 64 位 Windows 10/11；32 位系统或 Windows 7 无法运行当前构建。
5. 新版启动失败会弹窗说明原因。也可以查看日志：
   - 程序目录：`stag.log`
   - 本机缓存目录：`stag.log`
